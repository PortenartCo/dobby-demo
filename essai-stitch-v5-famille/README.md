# Dobby V5 familial — version d’essai

Copie non destructive de l’essai Stitch V5 avec les composants de synchronisation familiale activés par `family-v2.js`.

Production `/index.html`, essai V5 originel et pilote Sync V2 inchangés.

Le module courses emploie les tables V2 déjà créées. Pour les autres modules, l’activation du partage attend la migration `sql-proposals/dobby-v2-modules.sql` et une validation explicite par module. Santé et fichiers joints restent locaux.
