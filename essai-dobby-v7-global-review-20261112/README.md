# DOBBY V7 — Revue globale isolée

Entrée : `index.html`. Deux clients fictifs A et B dans des onglets du même navigateur, avec stockage indépendant et backend simulé commun. Les formulaires et writers sont ceux de l’application. Les contrôles de simulation permettent de synchroniser, de couper les réponses simulées et de réinitialiser ce seul essai.

Aucun compte réel, requête vers Supabase, migration SQL ou appel IA payant. La disponibilité partagée est simulée, sa migration réelle n’est pas appliquée. Les mémos partagés et les crédits de runes passent par leurs protocoles natifs ; les anciens mémos locaux nécessitent un import explicite. Les dépendances connues et les validations physiques iPhone sont décrites dans le rapport de livraison.

La simulation A/B nécessite HTTPS ou localhost, IndexedDB et Web Locks. Un manifeste retrace les sources, les transformations et les empreintes.
