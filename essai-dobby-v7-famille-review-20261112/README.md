# DOBBY V7 — Revue Famille isolée

Entrée : `index.html`, puis `essai-stitch-v7/famille.html?client=A` ou `?client=B`. Deux parents fictifs et trois profils dépendants (bébé, enfant, animal) permettent de parcourir les écrans Famille et leur politique native de démonstration. Les identités et les résultats magiques E05 préremplis sont fictifs. Les autorisations ne représentent pas une association de compte vérifiée par un serveur.

Les clients A et B partagent uniquement le backend simulé de cet essai dans le même navigateur. Le constructeur réutilise le pipeline global courant et conserve ses corrections de synchronisation, de restauration des documents et de réinitialisation. Le script du backend reste identique, à la substitution exacte de son espace de stockage près. Les formulaires, modules et writers restent natifs.

Aucun compte réel, aucune connexion à Supabase, aucune migration SQL, aucune invitation réelle ni appel IA payant. La politique CSP bloque les connexions externes. HTTPS ou localhost, IndexedDB et Web Locks sont nécessaires à la simulation A/B. Le manifeste retrace les sources, transformations et empreintes SHA-256. Le constructeur exige des sources commises par défaut ; `--allow-dirty` sert uniquement aux preuves locales. Chaque construction crée un nouveau répertoire et refuse de remplacer un essai existant.
