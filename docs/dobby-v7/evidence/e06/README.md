# E06 — preuves visuelles et fonctionnelles

Les noms, identifiants, sessions et données des tests sont des fixtures isolées. Aucun compte familial réel ni appel de production.

`before/` : compositions des HTML originaux immuables, scripts externes désactivés, polices DOBBY locales et utilitaires de dimensions équivalents. Les médias distants indisponibles restent vides : ces rendus ne prétendent pas restaurer un asset absent. Les `screen.png` fournis dans le ZIP restent la référence graphique originale.

`after/` : véritables scènes DOBBY pendant le parcours natif, données de fixtures, confirmations explicites. Comparaison visuelle manuelle, tests de débordement et de dimensions ; aucune prétention à une identité pixel à pixel.
