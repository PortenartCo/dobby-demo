# Captures comparatives de consolidation

Les comparaisons source utilisent les mêmes fixtures fictives avant et après la correction du lot. Les contrôles d’images attendent leur décodage ; la reprise E06 hébergée couvre explicitement les atlas CSS et leur peinture, avec diagnostic initial conservé. Le dock et le bandeau fixes peuvent traverser une capture longue à la position du viewport ; les tests contrôlent séparément débordements et commandes visibles. Les captures restent des preuves techniques, pas une validation UX utilisateur.
